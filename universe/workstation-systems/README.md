# BuildLang Workstation Systems, Biology, Quantum, and Robotics Kernels

Pure-BuildLang deterministic display calibration, plasma equilibrium, articulatory acoustics, hemodynamic flow, mycelial network percolation, origami kinematics, gravitational lensing, developmental robotics, satellite bathymetry, and optogenetic neuron kernels licensed under MIT and verified on buildc 1.15.0+.

- `sensorless_cal.bld` (`COL-041`, `E27`): Bayesian white-point drift estimator with Sharma 2005 CIEDE2000 color difference and planted thermal-runaway outlier rejection.
- `plasma_quantum_kcore.bld` (`PHY-073`, `N12`): Solovev Grad-Shafranov tokamak magnetic-flux equilibrium, WKB Gamow alpha-decay Geiger-Nuttall tunneling, and Casimir parallel-plate pressure kernel.
- `ipa_formant.bld` (`SIG-064`, `N19`): Articulatory Klatt cascade formant synthesizer for cardinal IPA vowels with Goertzel peak verification and planted unstable-pole guard.
- `flow_valves.bld` (`PHY-074`, `C3`): Three-element Windkessel arterial and hydraulic pressure pulse model with automatic overpressure safety-relief valve trip.
- `mycelium_net.bld` (`PHY-075`, `C4`): Murray-law vascular conductance optimization and root-contact percolation threshold solver with disconnected-graph rejection.
- `geom_fold.bld` (`GEO-026`, `G1`): Kepler FCC sphere-packing density verifier and Miura-ori rigid origami kinematics confirming negative in-plane Poisson ratio.
- `cosmo_lensing.bld` (`PHY-076`, `G3`): NFW dark-matter halo plus exponential disk flat galaxy rotation curve and Einstein ring angular radius solver.
- `dev_robotics.bld` (`OPT-054`, `AC6`): Matched-compute 2-link planar-arm reaching and inverted-pendulum staged sensorimotor curriculum benchmark.
- `grav_bathymetry.bld` (`GEO-027`, `N05`): Parker-Oldenburg downward-continuation satellite gravity bathymetry inversion recovering a submerged seamount with noise regularization guard.
- `neuro_opto.bld` (`PHY-077`, `G5`): Hodgkin-Huxley neuron coupled with Channelrhodopsin-2 light-gated conductance reproducing 20 Hz optical spike locking.

## Run

Run any kernel directly via `buildc check`, `buildc lint`, and `buildc run` in release mode on `universe/workstation-systems/<kernel>.bld`.
