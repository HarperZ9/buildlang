# Calibrate

The BuildLang calibration module files (`lib.bld` and `main.bld`) live in this folder as part of the Build Universe tree.

The standalone Python display calibration application (`calibrate_pro`) has moved to its maintained repository:

- https://github.com/HarperZ9/calibrate-pro

The older duplicate Python copy previously committed under `universe/calibrate/` has been removed to prevent drift.
