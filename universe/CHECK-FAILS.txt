# lex: no token stream. parse: the parser reports errors. types: the file parses and the type
# and effect check refuses it. universe/check.sh runs the check on every .bld file in CI and
# fails when a line here stops being true or a file fails that is not listed, so a fix to the
# compiler or to a module has to remove its line.

# not callable 19, BL0383 construct not supported yet 14, BL0402 effect performed but not
# declared 10, BL0325 value cannot be dereferenced 10. Most of these modules were written as
# a specification ahead of the compiler: they call library methods and fields that do not
